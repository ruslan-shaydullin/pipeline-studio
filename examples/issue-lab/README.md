# Issue lab

Небольшой проект для первого настоящего запуска Pipeline. Зависимости не нужны.

## Задача

Исправить `normalizeTags(tags)` в `tags.js`:

- обрезать пробелы и приводить строки к нижнему регистру;
- удалять пустые значения и повторения, сохраняя порядок первого появления;
- не менять входной массив.

Проверка: `npm test`. Сейчас три проверки падают.

Pipeline работает с копией этой папки, поэтому исходный пример остаётся доступен для новых запусков.
